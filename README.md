# Yandex Music Download Addon

Неофициальное дополнение для Яндекс Музыки на Windows. Скачивайте треки в MP3 или FLAC прямо из приложения и следите за загрузками в одном месте.

## Возможности

- Кнопки скачивания рядом с треками и в плеере.
- Выбор формата MP3 или FLAC.
- Очередь с прогрессом и история загрузок.
- Быстрый переход к сохранённым файлам.

## Установка

1. Установите Яндекс Музыку и войдите в свой аккаунт.
2. Скачайте **[YandexMusicAddon-Setup.cmd](https://github.com/kesevone/yandex-music-download-addon/releases/latest/download/YandexMusicAddon-Setup.cmd)** из последнего релиза.
3. Откройте файл двойным кликом и выберите установку. Этапы и скачивание компонентов отображаются в терминале.
4. Открывайте Яндекс Музыку привычным ярлыком. Если она уже работала без дополнения, один раз полностью закройте её и снова откройте этим ярлыком.

Установщик сам подготовит необходимые компоненты. Требуются Windows 10/11 x64, установленная Яндекс Музыка и интернет.

Проверенная версия клиента: **5.122.0**. После изменения внутренних компонентов Яндекс Музыки может потребоваться обновление аддона.

## Как пользоваться

Нажмите кнопку скачивания у трека и выберите формат. Загрузка появится в очереди; её можно открыть кнопкой над плеером. Закрытие панели не прерывает скачивание.

Треки загружаются последовательно. Ожидающие задания можно убрать из очереди, а готовые файлы — открыть в Проводнике.

Музыка сохраняется в **Загрузки / Yandex Music**. Существующие файлы не перезаписываются.

FLAC сохраняется без перекодирования. Доступность треков и форматов зависит от аккаунта и каталога Яндекс Музыки.

## Обновление и удаление

Для обновления снова запустите установщик нового релиза. Он сохраняет очередь, историю и резервные копии исходных ярлыков.

Для отключения выберите удаление в том же установщике. Исходные ярлыки восстанавливаются, помощник завершает текущую загрузку и выключается. Скачанные песни сохраняются.

## Локальные данные

Дополнение и его данные находятся в `%LOCALAPPDATA%\YandexMusicDownloadAddon`. Очередь и последние 100 записей истории сохраняются между запусками. Для скачивания используется аккаунт, в который вы вошли в приложении; локальная сессия защищена Windows DPAPI.

Аддон не отправляет телеметрию. EXE и ASAR приложения не изменяются; подключение работает через ярлыки, исходные копии которых сохраняются для отката.

## Сборка из исходников

```powershell
python scripts/build.py
python -m unittest discover -s tests -v
powershell -NoProfile -ExecutionPolicy Bypass -File tests/test_installer.ps1
```

Сборка создаёт `dist/YandexMusicAddon-Setup.cmd` и файл SHA256. Файл содержит исходники дополнения и установщик; портативные компоненты скачиваются отдельно с проверкой SHA256 из `installer/dependencies.json`. Пользовательские сессии, история, аудио и файлы оригинального приложения в пакет не входят.

`src` содержит интерфейс и локальный помощник, `installer` — установку и откат, `scripts` — сборку, `tests` — проверки сохранения аудио, сессии и упаковки.
